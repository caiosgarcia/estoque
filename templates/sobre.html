📦 O Projeto

Tema: Sistema de Controle de Estoque


Objetivo: Desenvolver uma aplicação web para gerenciamento de estoque, permitindo o controle de produtos, categorias, movimentações de entrada e saída, além de exportação e importação de dados.


Tecnologias:

  • Python + Flask (back-end)
  • SQLite (banco de dados)
  • HTML/CSS (interfaces)
  • Módulo requests (importação)
  • Módulo zipfile / json (exportação)
